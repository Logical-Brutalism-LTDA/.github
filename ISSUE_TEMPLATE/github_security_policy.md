# Security Policy

## Supported Versions

Only the latest published release of `logical-brutalism` (PyPI / NPM) and the active `main` branch of each repository under this organization receive security updates.

| Version | Supported |
| :--- | :---: |
| Latest (`v1.4.x`) | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security issue (such as XSS vectors in templates, unsafe CLI file operations, or dependency vulnerabilities), please report it privately using one of the following channels:

1. **GitHub Private Vulnerability Reporting:** Use the **"Report a vulnerability"** button under the **Security** tab of the affected repository.
2. **Direct Email:** Contact the maintainer directly at `security@matheuslacerda.dev` (or your preferred contact email).

### What to Include

- A concise description of the vulnerability and its potential impact.
- Exact steps or a minimal proof-of-concept to reproduce the issue.
- Affected package version, runtime (Python/Node), or commit hash.

## Response Timeline

- **Acknowledgment:** Within 48 hours of receiving the report.
- **Triage & Fix:** Confirmed vulnerabilities are prioritized and patched as quickly as possible, followed by a coordinated release and credit to the reporter (if desired).
